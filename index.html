About Light Kali

The first Web OS from Iran with a global ambition.

Light Kali, also written as LightKali or Kali Light, is a Linux-based Web OS project from Iran focused on creating a modern web-first operating environment. The project combines a responsive interface with modular packages, cybersecurity-oriented workflows and a developer ecosystem.

Light Kali's vision is not limited to a local audience. The project aims to build a distinctive global Web OS platform while maintaining a strong Iranian identity and contributing a new direction to web-native operating environments.

The project website is organized around technical documentation, packages, developer resources, Web OS architecture, project updates, community information and supporting content so each major subject can be discovered and understood independently.

Frequently Asked Questions

About Light Kali, Web OS and the project.

Core information about Light Kali, LightKali, Kali Light, its Linux foundation and its Web OS direction.

What is Light Kali?
Light Kali is a Linux-based cybersecurity Web OS project from Iran focused on a responsive web-first interface, modular packages and practical security workflows.
What is the Light Kali Web OS?
The Light Kali Web OS direction treats web technologies as an important part of the user-facing operating environment while keeping Linux concepts and system capabilities close to the user.
Is Light Kali the same as Kali Linux?
No. Light Kali is a separate project with its own Web OS direction, interface, package ecosystem and development resources.
Is Light Kali the first Web OS from Iran?
Light Kali is presented by the project as the first Web OS from Iran. The project's long-term goal is to establish a distinctive Iranian Web OS identity with a global technical audience.
What are Light Kali packages?
Light Kali packages provide a modular way to organize specialized capabilities around the project's core Web OS environment.
Who is Light Kali for?
Light Kali is intended for technical users, Linux learners, cybersecurity learners, developers and people interested in web-first operating environments.
Where can I find the official Light Kali news channel?
The official Light Kali news channel is available on Telegram at t.me/LightKali.
