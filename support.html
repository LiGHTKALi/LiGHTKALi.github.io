Frequently Asked Questions

A practical support guide for using Light Kali and working with its package ecosystem.

What is Light Kali Support?
Support provides guidance and project information for users who encounter problems with the WebOS, packages, or supported project workflows.
Where should I start when something fails?
First reload the WebOS and repeat the operation. Check whether the issue is limited to one package or affects the core environment.
A package will not install. What should I check?
Verify the package name, package availability, connection, and the package manager output. External package sources may also be subject to security checks.
What if a package behaves unexpectedly?
Stop using the package and record the command, package name, version if available, and the exact error output. Do not provide passwords, tokens, or other private information.
Does Light Kali require installation?
No. Light Kali is designed as a browser-based environment and does not require replacement of the operating system installed on the device.
Can I create my own package?
Yes. Developers can create independent packages, test them, prepare them for validation, and submit eligible packages for publication.
Can I modify the Light Kali Core?
The Light Kali Core is governed by the project license. Independent packages and extensions are the supported way to add functionality.
How can I report a serious problem?
For a serious issue that cannot be resolved through normal support information, contact kalilightstudio@gmail.com with a clear description of the problem.
What information should I include in a support request?
Include the page or package involved, the steps that caused the problem, the exact error message, your browser and device, and any relevant non-sensitive details.
Should I send passwords or private tokens?
No. Never include passwords, session tokens, API keys, cookies, private credentials, or other sensitive information in a support request.
Can I request a new package or feature?
Yes. Describe the use case and the desired result. Feature and package requests can be reviewed as part of the project development process.
Where can I learn about packages?
Use the Package Store for available packages and the Developers section for package creation and publication information.
Where can I read the project license?
The complete Light Kali Restricted Use License is available on the License page.
Where can I follow project updates?
The official Light Kali Telegram channel is available at t.me/LightKali.

Need Serious Help?

For serious problems that cannot be resolved through the support information above, contact kalilightstudio@gmail.com with a clear description of the issue and relevant non-sensitive details.
